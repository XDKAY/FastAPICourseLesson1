# Задание по программированию:
Это задание базового уровня. Оно предназначено для закрепления материала лекции и не требует дополнительного изучения. Просто примените полученные знания на практике.

Создайте новый файл app.py и напишите код для FastAPI-приложения, которое при обращении к корневому URL (/) будет возвращать JSON-ответ {"message": "Добро пожаловать в моё приложение FastAPI!"}.

Дополнительно:

Запустите приложение с помощью uvicorn в режиме разработки (с флагом автоперезагрузки).
Откройте браузер и проверьте, корректно ли отображается ваш ответ.
Без остановки uvicorn'а измените в коде текст ответа на JSON: {"message": "Авторелоад действительно работает"} и проверьте через браузер, что теперь возвращается новое сообщение.
Измените имя переменной приложения (как во втором примере лекции) и убедитесь, что теперь uvicorn требует другой аргумент для запуска.

# Запуск приложения

1. **Клонирование репозитория**

`git clone git@github.com:XDKAY/FastAPICourseLesson1.git`

2. **Перейти в проект**

`cd FastAPICourseLesson1`

3. **Создание виртуального окружения**

`uv venv`

4. **Установка зависимостей**

`uv sync`

5. **Запуск проекта**

`uvicorn main:app --reload`

Переходим на http://127.0.0.1:8000/
